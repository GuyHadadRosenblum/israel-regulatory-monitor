# מערכת ניטור ובקרת רגולציה

[פתיחת ההדגמה](https://guyhadadrosenblum.github.io/israel-regulatory-monitor/)

המערכת נבנתה על ידי Guy Hadad Rosenblum במסגרת העבודה ברשות האסדרה הישראלית, לאחר זיהוי צורך לצמצם ניטור ידני חוזר של פרסומי חקיקה והצלבתם עם פניות רשמיות.

הממשק החדש מאפשר לחפש רגולציות, לסנן לפי משרד וסטטוס, לפתוח את פרטי ההתאמה ולייצא דוח. במסך ״על הפרויקט״ אפשר לבדוק באופן אינטראקטיבי כיצד שינוי הטקסט משפיע על ציון הדמיון.

## קישור למעסיקים

הקישור הציבורי פותח הדגמה ללא התקנה, חשבון או מפתחות. הרשומות סינתטיות ומסומנות כך במפורש. כפתור ההדגמה ממחיש את שלבי התהליך; הוא אינו מריץ איסוף חי או קריאות AI.

## הפעלה מלאה

1. מתקינים Docker Desktop ומורידים את המאגר.
2. מריצים `docker compose up --build` ופותחים `http://localhost:8000`.
3. לשימוש במקורות אמיתיים מעתיקים את `.env.example` אל `.env` ומגדירים אישורי Google אישיים בהתאם ל־README הראשי. בתוך Docker נתיב המפתח הוא `/app/config/your-key.json`.
4. משתפים את הגיליון עם חשבון השירות ובוחרים ״הפעלה אמיתית״ בממשק.

סיכום AI ושליחת Telegram כבויים כברירת מחדל. ניתן להפעיל AI מקומית עם פרויקט והרשאות מתאימים; ההפעלה עשויה להיות כרוכה בתשלום ל־Google.

העלאת Excel מ־Monday במסך הדוחות מחשבת מועדי יעד לפי הלוגיקה הקיימת: 14 ימים, או 74 ימים כאשר הוחלט לייעץ. תרשימי הגאנט וטבלת הזרם ההיסטורית זמינים דרך הסקריפטים המקוריים לפי ההוראות במאגר.

## מגבלות

ציון הדמיון הוא חפיפה בין קבוצות מילים ואינו הסתברות לנכונות ההתאמה. סיווג AI אינו החלטה רשמית ונדרשת בקרה אנושית. האתר הציבורי הוא הצגה אישית של הפרויקט ואינו אתר ממשלתי רשמי.
